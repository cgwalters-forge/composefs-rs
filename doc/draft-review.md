publication; the caller must not reproduce them.

## Result contract for tracker rollout

An accepted result is a real Actions-bot `APPROVED` review at `commit_id=head`,
with exactly one `agent-board-draft-review` JSON fence and one existing gh-aw
run marker generated by trusted publication code. A PR body, status, comment,
agent-written marker or implementation job title is not result provenance.

The JSON uses `schema=agent-board/draft-review/v1`, `repository`, numeric `pr`,
`reviewed_head`, and **exact current strings** `title` and `description`.
It also requires `semantic_diff`, `description_assessment`, `change_category`,
`risk`, `evidence` and `reason`. Quick requires `semantic_diff=pass`,
`description_assessment=matches`, `risk=none`, and actual concrete diff and
description inspection. Categories are `docs`, `dependencies`, `ci`,
`mechanical`, or `narrow_fix_with_test`; paths alone cannot attest semantics.
Evidence/reason must each be nonempty, single-line and at most 1024 bytes;
the entire review is at most 8192 bytes. Unknown fields, duplicate fences,
unsupported schema or repo/PR/head/title/description mismatch invalidate it.
No synthetic successful result is supplied here.

Tracker must verify immutable Actions-bot identity, a successful completed run
of its configured base/default-branch dispatch workflow with matching run
title and head, and a preceding bot-authored durable head reservation. The
review must be submitted within the latest attempt. Read at most 100 jobs of
that exact attempt, completely: exactly one successful completed job named
`agent-board-review-result-v1` must identify the same run, and contain the
submission timestamp within its start/end interval. Reserve this job name
only for the independently checked review writer, conditional on `kind=review`.
Old callers without this contract stay deep. These checks trust configured
base workflow writers; they do not protect against a compromised base.

Even verified semantics cannot bypass deterministic vetoes: at most 5 files
and 150 total added/deleted lines, complete file/patch evidence (both names of
renames), conservative path/risk rules, and complete nonempty current-head
green CI including required checks and protection/ruleset reads. Missing,
pending, failed, partial or unknown CI stays deep. Reevaluate edits, retargets
and checks every pass. Local `doc/` is not the classifier's allowlisted
`docs/`; do not widen that upstream policy here. No classification grants
ready, promotion, fix or merge authority.
